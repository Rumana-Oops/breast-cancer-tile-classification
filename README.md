# breast-cancer-tile-classification
Breast cancer tile classification using CNN, Zero‑Shot CLIP, and mask‑based labeling.
## Download Dataset

This project uses a Kaggle dataset:
https://www.kaggle.com/datasets/deepeshghimire/specialization-project

To download it:

1. Install Kaggle CLI:
   pip install kaggle

2. Place your kaggle.json API key in:
   ~/.kaggle/kaggle.json

3. Run:
   bash scripts/download_dataset.sh
